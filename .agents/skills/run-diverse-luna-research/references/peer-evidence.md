# Peer clarification after independent evidence collection

Read when scouts need to reconcile conflicting evidence or clarify an interface between research cells. The root assigns exact peer IDs, shared non-sensitive source plane, permitted questions, acknowledgement deadline and a small message/round budget. Independent cells normally return their first packets to root without seeing others' conclusions.

After those initial packets are recorded, root may authorize direct internal `send_message` clarification between active peers. Use an issue ID, exact claim, canonical source/section or artifact hash, requested check, and deadline. Public prompt-only scouts may exchange only public non-sensitive evidence. Internal agent messaging is distinct from externally sending email, chat, or provider data; no external send is authorized here.

Peers acknowledge the question and answer from original evidence. Copy root on contradictions, changed conclusions, missing access, and unresolved questions. Shared conclusions are now dependent evidence: messaging never creates independent corroboration. Preserve original packets, source families and the correction chain.

After one unanswered retry, incompatible access, or the assigned round/deadline limit, send root both claims and the exact unresolved question. Root decides on a fresh bounded verifier cell or records a gap. Peers do not change source-plane permissions, assignment scope, budgets, or shared files. Idle or completed peers require root scheduling; sending a message alone does not restart them. Native continuation supports related refinement. Fully attributed accepted rows retain initial-turn receipts; record other operational evidence and root source verification separately under [v2-runtime.md](v2-runtime.md).

Root reopens the original sources and message trace before synthesis. An acknowledgement, consensus, or tool-delivery receipt does not prove the claim. A verifier used for independent evidence must start without the prior peers' conclusions.
